你好，我是 EliWung 👋

这里是我的个人博客，用来存放一些想法、笔记和踩过的坑。 相比发在社交平台上，我更希望有一个完全属于自己的地方，把零散的知识整理成体系， 也顺便记录一下自己是怎么一点点长大的。

我平时关注的东西比较杂：写代码、做点小产品、看看别人的设计，偶尔也会研究一些和主业无关的玩意儿。 这个站点基于 Jekyll 和 Hux Blog 主题搭建，托管在 GitHub Pages 上， 全部代码开源在我的 GitHub 主页 —— 如果你也想要一个，直接 fork 走改改就行。

关于这个博客

  • 写作：用 Markdown，提交即发布，不需要任何后台。
  • 内容：技术笔记为主，偶尔夹带一些生活流水账。
  • 态度：尽量写自己真正想清楚的东西，不凑字数。

Hi, I'm EliWung 👋

This is my personal blog — a place for thoughts, notes, and lessons learned the hard way. Rather than scattering everything across social platforms, I'd rather own a corner of the internet where I can turn loose fragments into something structured, and keep a record of how I grow along the way.

My interests are a bit of a mix: coding, building small products, looking at good design, and occasionally diving into things that have nothing to do with my day job. This site is built with Jekyll and the Hux Blog theme, hosted on GitHub Pages. All the code is open on my GitHub — feel free to fork it and make it yours.
